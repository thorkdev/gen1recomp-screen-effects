# Screen Effects

Adds a CRT/film-grain look (scanlines, a corner vignette, mild edge
chromatic aberration and animated grain) as a SCREEN FX row on the OPTIONS
menu (OFF / LIGHT / HEAVY), with FILM GRAIN and SCANLINES as separate
on/off rows underneath it.

For anyone who wants the classic-display look without giving up a 3D world
mode: it's a present-stage render pipeline only, so it folds over whatever
already rendered the frame (flat 2D, TILT, or a voxel diorama from
`dramatic-shape` / `BATTLE_ART_VOXEL_FORK`) rather than competing with it.
